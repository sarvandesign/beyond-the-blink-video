Privacy Policy

Beyond the Blink is a personal tool that uploads videos to the owner's own YouTube channel. It is not offered to the public.

What we access

With the owner's permission, the app uses the YouTube Data API to upload and schedule videos on the owner's channel. It does not read or collect data about other users.

What we store

The app stores one sign-in token for the owner's Google account so it can upload videos. The token is kept in the owner's private Cloudflare account and is not shared with anyone.

Sharing

We do not sell, share, or disclose any user data to third parties.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy. The owner can revoke access any time at myaccount.google.com/permissions.
